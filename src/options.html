Listas de filtros

As listas incluídas no pacote funcionam sem internet. Atualizações baixam texto de filtros e compilam apenas regras de rede e seletores cosméticos compatíveis; não executam JavaScript remoto.

Sites permitidos

Nestes sites, o bloqueio de rede e a filtragem cosmética ficam pausados.

Minhas regras

Regras cosméticas usam domínio e seletor CSS. Regras de rede aceitam o subconjunto seguro `||dominio^` com opções como `$script` ou `$third-party`.

Estatísticas

A contagem de regras DNR depende da API de depuração, disponível em extensões descompactadas. Fora desse modo, os números anteriores permanecem parciais; nenhum bloqueio é inferido a partir de elementos ocultos.

Dados, diagnósticos e licenças

Privacidade

Configurações e contadores ficam no armazenamento local do navegador. A extensão acessa páginas para aplicar filtros e busca listas somente dos endereços configurados.
